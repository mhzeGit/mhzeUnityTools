# Review Actual Outputs

Open the saved image before reporting success. A generated description, completed tool call or TOP label does not establish correctness.

| Criterion | Check |
| --- | --- |
| Object identity | Resembles the requested item and agreed shape; essential features are present |
| Chosen style | Matches the user's rendering, palette, contour and detail choices, including flatter cartoons |
| Views | Side is level orthographic; front/top is the specified projection; hero explains depth |
| Same object | Geometry, proportions, parts, state and marks agree; distinguish expected occlusion from missing parts |
| Form readability | Thickness and relationships are clear without inventing a different object or claiming engineering validity |
| Presentation | Correct panel count, complete silhouettes, quiet backdrop, useful scale and labels |
| Delivery | File exists and opens; format and dimensions are actual; native prompt and reference roles are retained |

Optional 1-5 scores are editorial judgments, not guarantees. Identity and explicit user feedback outrank aggregate scores. Reject a stylish image of the wrong object.

Correct named defects while preserving approved aspects. After repeated failure, change the reference or approach. Distinguish prepared, submitted, pending, failed and visually verified results. Report remaining limitations; do not claim perfect or identical geometry without evidence. Respect a request to stop.
