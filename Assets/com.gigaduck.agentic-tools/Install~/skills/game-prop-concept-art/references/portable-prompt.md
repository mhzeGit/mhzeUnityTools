# Portable Prop Prompt

Replace the bracketed fields. STYLE may be flatter hand-painted cartoon or painted stylized 3D, according to the user's choice. Choose FRONT or TOP. Attach references and explain their roles, or omit the reference sentence if none exist. DETAILS should describe the recognizable object, not an invented engineering specification.

---

Create a landscape reference sheet of ONE [OBJECT] for a [PERIOD / SETTING] game.

Design: [RECOGNIZABLE SHAPE, MATERIALS, STATE, IMPORTANT FEATURES]. Preserve the item's familiar identity. [STYLE REFERENCE] establishes rendering and palette; [SHAPE REFERENCE] establishes silhouette and parts. Do not copy rejected geometry or unrelated objects from a style image.

Rendering: [STYLE]. Moderate detail, chunky gently rounded handmade forms, broad painted material strokes, restrained highlights and mostly quiet surfaces. Use the chosen palette and contours. Keep thickness understandable; do not replace a chosen cartoon treatment with photorealism or force 3D rendering.

Exactly THREE drawings in ONE horizontal row. LEFT: three-quarter hero with useful depth. MIDDLE: TRUE ORTHOGRAPHIC SIDE, camera perfectly level, zero perspective, showing the actual profile. RIGHT: TRUE ORTHOGRAPHIC [FRONT / TOP]; top is directly vertically overhead with zero perspective. Keep the same natural resting orientation and state. Change cameras, not design or pose. A side view must never be another three-quarter view. Do not alter parts to simplify a projection.

ONE identical object across panels: same proportions, parts, state and important marks. Consistent nominal scale; a narrow front profile remains narrow. Full silhouettes, generous margins, tiny THREE-QUARTER, SIDE and [FRONT / TOP] labels. No extra rows or duplicates.

Clean pale neutral backdrop, restrained neutral lighting and minimal contact shadow. Keep colours readable. Add no scenery, hands, unrelated props, modern branding or fantasy decoration unless requested. Avoid photographic microtexture and dense scratch noise unless part of the chosen style.

Inspect identity, selected style, projections and agreement between views. Correct named defects while preserving approved aspects. After two unsuccessful corrections of the same issue, reassess the shape reference. Report failures and remaining defects honestly; respect a request to stop. Save the exact submitted prompt and actual image when file tools are available.
