# Application icons

The PNGs are unmodified 32-pixel application icons extracted from installed Blender, Graphmat and Affinity executables. They identify the applications opened by the source shortcuts; they are not Gigaduck artwork. Application names, icons and trademarks belong to their respective owners.

Only these flattened PNGs are shipped. Extraction tooling and provenance stay in the external resource library under `05_Library/ToolsAndTemplates/AssetSources/Source/Icons/`.
